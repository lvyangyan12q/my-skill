# SSH 连接

## 必要参数

从用户消息或当前对话取得以下四项，已有的不重复询问，缺少的再向用户确认：

- 私钥文件路径：当前电脑上的路径，不是 .pub 公钥文件。
- 服务器 IP。
- SSH 端口。
- 登录用户名。

## 连接命令

将参数代入以下命令，路径加引号；不要在用户名的 @ 或文件名的 _ 前添加转义反斜杠：

~~~sh
ssh -p PORT -i "PRIVATE_KEY_PATH" USERNAME@IP
~~~

例如，在 PowerShell 中：

~~~powershell
ssh -p 32768 -i "C:UsersAdministrator.sshid_ed25519" cet@10.12.140.65
~~~

示例不是默认连接目标。AI 执行单条只读命令时，在末尾追加远端命令，并增加非交互和超时选项：

~~~sh
ssh -o BatchMode=yes -o ConnectTimeout=10 -o StrictHostKeyChecking=yes -p PORT -i "PRIVATE_KEY_PATH" USERNAME@IP "hostname"
~~~

连接成功后执行用户要求的只读任务。失败时报告实际错误和具体缺失条件，不自动修改配置；首次主机信任或私钥解锁需要用户在本机完成。

## 操作限制

- 仅允许只读任务，如查看日志、配置、容器和服务状态。
- 禁止删除、清空、覆盖文件或数据、删库、格式化、删除容器/镜像/卷，以及通过脚本或 API 间接执行同类操作。
- 禁止重启或停止服务、终止进程、修改配置或权限、安装卸载及重建部署。需要修复时只给诊断和建议，不执行变更。
- 私钥只用于 SSH 认证，不读取、展示或复制其内容；日志输出隐藏口令、令牌等敏感信息。
- 不关闭主机指纹校验，不删除旧的信任记录。连接授权不解除上述限制。
